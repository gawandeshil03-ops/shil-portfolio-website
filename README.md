# Shil Gawande Portfolio

Recruiter-focused portfolio built from the AnimFolio Data Scientist template direction and customized around selected GitHub projects.

## Deploy on GitHub Pages
1. Upload everything in this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`.
4. Save.

The site is fully static HTML/CSS and needs no build step.
